## 물류관리

물류관리(Logistics management)는 원자재, 부품, 완제품을 생산지에서 소비지까지 효율적으로 이동, 보관, 관리하여 고객이 원하는 시점에 필요한 제품을 공급하는 관리 활동이다. 주요 기능으로는 운송, 보관, 하역, 보장, 정보관리가 있으며 조달물류, 생산물류, 판매물류, 회수물류로 구분할 수 있다. 공장에서는 생산라인에 필요한 자재를 적시에 공급하고 완제품을 고객에게 신속하게 출하하는 것이 핵심 역할이다. 최근에는 WMS, TMS, AGV, AMR, RFID와 같은 기술을 활용하여 물류 효율과 정확성을 높이고 있으며 물류관리는 SCM을 구성하는 핵심 기능으로 공급망 전체 경쟁력 향상에 중요한 역할을 한다.

즉, 물류관리는 제품 이동(Transportation)과 보관(Storage)을 최적화하여 비용을 절감하고 고객 만족도를 높이는 활동이다.

### 물류관리 목적

물류관리 궁극적 목적은 **적시에(Just In Time), 적정 수량(Right Quantity)을 적정 장소(Right Place)에 최소 비용으로 공급**하는 것이다.

- 물류비 절감
- 납기 준수(On-Time Delivery)
- 재고 최적화
- 운송 효율 향상
- 고객 만족도 향상
- 원활한 공급망 운영

### 주요 기능

물류관리는 크게 다섯가지 기능으로 구성된다.

| 기능                          | 설명               |
| --------------------------- | ---------------- |
| 운송(Transportation)          | 제품과 자재를 이동       |
| 보관(Warehousing)             | 창고에 보관 및 관리      |
| 하역(Material Handling)       | 상·하차 및 공정 간 이동   |
| 포장(Packaging)               | 제품 보호 및 운송 효율 향상 |
| 정보관리(Logistics Information) | 재고와 배송 정보 관리     |


### 물류 종류

1. **조달물류** (Inbound Logistics)  
   원자재와 부품을 공급업체에서 공장으로 운송하는 활동이다. 철강 입고, 반도체 입고, 배터리 입고 등이 해당된다.
2. **생산물류** (Production Logistics)  
   공장 내부에서 자재와 반제품을 공정 간 이동시키는 활동이다. 공정간 자재를 적시에 공급하는 것이 핵심이다.  
   ```mermaid
   flowchart LR
       A[프레스]
       B[용접]
       C[도장]
       D[조립]
   
   A --> B --> C --> D
   ```
3. **판매물류** (Outbound Logistics)  
   완제품을 고객이나 대리점으로 출하하는 활동이다.  
   ```mermaid
   flowchart LR
       A[완제품 창고]
       B[뮬류센터]
       C[대리점]
       D[고객]
   
   A --> B --> C --> D
   ```   
4. **회수물류** (Reverse Logistics)  
   고객으로부터 반품, 불량품, 재활용 제품 등을 회수하는 활동이다. 불량 제품 회수, 리콜, 폐배터리 회수, 재활용 등이 해당된다. 최근 ESG와 순환경제 중요성이 커지면서 회수물류 역활도 확대되고 있다.

### 핵심 관리 대상

| 관리 항목 | 설명            |
| ----- | ------------- |
| 재고관리  | 적정 재고 유지      |
| 창고관리  | 보관 위치 및 공간 관리 |
| 운송관리  | 운송 수단과 경로 최적화 |
| 납기관리  | 고객 납기 준수      |
| 배송관리  | 배송 일정과 추적     |
| 포장관리  | 제품 보호 및 운송 효율 |

### 대표적인 물류 관리 기법과 시스템

1. **JIT** (Just In Time)  
   필요한 자재를 필요한 시점에 필요한 수량만 공급하는 방식이다. 재고 감소와 창고 비용 절감 효과가 있으나 공급이 지연되면 생산라인이 중단될 수 있다.
2. **Cross docking**  
   창고에 장기간 보관하지 않고 입고 즉시 출고하는 방식이다. 즉 트럭 입고 → 분류 → 즉시 출고 형태이다. 창고 비용을 절감하고 배송 시간을 단축시킬 수 있다. 대형 유통업체에서 많이 사용하고 있으며 대표적으로 월마트(WALMART)가 있다.
3. **Milk Run**  
   한 대 차량이 여러 공급업체를 순회하면서 자재를 수거하는 방식이다. 운송 비용을 절감하고 차량 활용률을 향상할 수 있다. 자동차 산업에서 널리 활용된다.
4. **Hub & Spoke**  
   중앙 물류센터(Hub)를 거쳐 각 지역(Spoke)으로 배송하는 방식이다. 운송 경로를 단순화하고 배송 효율을 높일 수 있다.

물류관리 관련 대표적인 시스템은 다음과 같다.

| 시스템                                    | 역할                    |
| -------------------------------------- | --------------------- |
| WMS (Warehouse Management System)      | 창고 관리 및 재고 관리         |
| TMS (Transportation Management System) | 운송 계획 및 차량 관리         |
| MES (Manufacturing Execution System)   | 생산과 생산물류 관리           |
| ERP (Enterprise Resource Planning)     | 구매, 재고, 회계 등 기업 자원 관리 |
| SCM (Supply Chain Management)          | 공급망 전체 최적화            |


## 재고관리

재고관리(Inventory management)는 생산과 판매활동이 원활하게 이루어질 수 있도록 원자재, 재공품, 완제품 등 재고를 적정 수준으로 유지하면서 재고 비용과 결품 위험을 최소화하는 관리 활동이다. 재고가 너무 많으면 보관 비용과 자금 부담이 증가하고 반면 재고가 너무 적으면 생산 중단과 납기 지연이 발생하기 때문에 최적 재고 수준을 유지하는 것이 중요하다. 주요 관리방법으로는 ABC 분석, EOQ, 안전재고, MRP, JIT 등이 있으며 최근에는 ERP, MES, WMS, AI 기반 수요 예측 기술을 활용하여 실시간 재고 최적화를 수행하고 있다.

즉, 재고관리는 **필요한 재고를 확보하되 불필요한 재고는 줄이는 균형 관리**이다.

### 재고관리 목적

기업 입장에서는 재고는 필요하지만 비용을 발생시키는 요소가 된다.

재고가 많은 경우 다음과 같은 문제가 발생한다.

- 보관 비용 증가
- 자금 회전율 저하
- 제품 노후화 및 폐기 발생
- 공간 부족

반대로 재고가 너무 적으면 다음과 같은 문제가 발생한다.

- 생산라인 정지
- 고객 납기 지연
- 긴급 구매 비용 증가

따라서 재고관리 핵심 목적은 다음과 같다.

| 목적        | 설명               |
| --------- | ---------------- |
| 생산 안정화    | 필요한 자재를 안정적으로 공급 |
| 납기 준수     | 고객 주문에 대응        |
| 재고 비용 최소화 | 보관 및 관리 비용 절감    |
| 재고 회전율 향상 | 보유 재고의 효율적 활용    |
| 공급 리스크 대응 | 공급 차질 대비         |

### 재고 종류

#### 생산활동별 기준

제조업에서는 재고를 크게 4가지로 구분한다.

1. **원자재 재고**(Raw Material Inventory)  
   제품 생산 정에 필요한 재료이다. 철강, 반도체 웨이퍼, 플라스틱 원료 등이 해당된다.
2. **재공품** (WIP, Work In Process)  
   생산 과정 중에 있는 제품이다. 이는 아직 완제품이 되지 않은 상태를 의미하며 조립 중인 Sub-ass'y 등이 해당 된다.
3. **완제품 재고** (Finished Goods Inventory)  
   생산이 완료되면 판매 가능한 제품이 된다. 출하 대기 중인 스마트폰, 판매 대기 중인 자동차 등이 해당된다.
4. **MRO 재고** (Maintenance, Repair and Operation)  
   생산 설비 유지보수를 위한 재고이다. 베어링, 공구, 소모품, 윤활유 등이 해당된다.

#### 기능별 분류

재고는 기능에 따라 다음과 같이 분류할 수 있다.

| 구분   | 발생 원인       | 관리 목적    |
| ---- | ----------- | -------- |
| 주기재고 | 주문·생산 주기    | 경제적 구매   |
| 안전재고 | 불확실성 대응     | 생산 중단 방지 |
| 수송재고 | 운송 시간       | 공급 과정 관리 |
| 예측재고 | 미래 수요 대비    | 성수기 대응   |
| 완충재고 | 공정 불균형      | 라인 안정화   |
| 투기재고 | 가격·공급 변화 예상 | 비용 절감    |
| 불용재고 | 사용 중단       | 재고 감축    |

1. **주기재고**(Cycle stock)  
   정기적인 생산 또는 구매할돵에서 발생하는 정상적인 재고로, 주문 도는 생산 주기 때문에 발생하는 기본 재고이다. 이는 기업이 자재를 매일 조금씩 구매하기보다는 일정량을 한 번에 구매하면서 발생한다. 구매를 한번에 진행하는 이유는 주문 비용을 절감하고 운송 효율을 향상하고 구매 관련 편의성 때문이다. 예를 들어 하루 볼트 사용량이 1000개, 매 주문시 일주일치 7000개 입고, 하루 사용하고 나면 남는 6000개가 주기재고가 된다. 주요 관리 방법으로 EOQ, 주문주기 관리, Lot Size 최적화 등이 있다.
2. **안전재고**(Safety stock)  
   수요 변동이나 공급 지연과 같은 불확실성에 대비하기 위해 추가로 보유하는 재고이다. 생산현장에서 매우 중요한 개념으로 현실에서는 계획대로 실행되지 않기 때문에 발생한다. 즉 공급업체 납품 지연, 갑작스러운 생산 증가, 품질 문제로 부품 폐기, 설비 이상 등 이런 상황에 대비하는 보호 재고이다. 안전재고가 많은 경우 재고 비용이 증가하고 너무 적으면 생산라인 정지 위험이 있다. 따라서 적정 안전재고 수준 설정이 필요하다.
3. **수송재고**(Transportation Inventory, Pipeline Inventory)  
   공급 과정에서 이동 중이기 때문에 발생하는 재고이다. 창고에 있는 재고가 아니라 운송 중인 재고를 의미한다. 한국 공장에서 미국 공장으로 부품을 보낼 경우 운송 시간이 30일이라고 가정하면 하루 사용량 1,000개일 때 총 1,000개 * 30일 = 30,000개는 이동중이므로 사용할 수 없다. 이 30,000개가 수송재고이다. 운송 시간이 길어질수록 재고가 증가함으로 운송 거리 단축, 물류 개선, 공급업체 지역화, 운송 방식 개선 등의 감소 방안을 검토해야 한다.
4. **예측재고**(Anticipation Inventory)  
   미래 수요 증가나 공급 부족을 예상하여 미리 확보하는 재고이다. 에어컨 제조업체가 여름 성수기 전 부품 확보 및 완제품을 생산하면서 발생하는 재고이다. 명절 선물세트, 겨울 난방제품, 신제품 출시 초기 물량 등이 이에 해당한다.
5. **완충재고**(Buffer stock)  
   공정 간 생산능력 차이나 작업 불균형을 흡수하기 위한 재고이다. 공장 내부에서 매우 중요하다. 공정 A는 시간당 100개, 공정 B는 시간당 80개 생산할 경우 공정 간 생산 차이가 발생한다. 공정 B에 일정량 재공품을 유지함으로써 작업 불균형을 맞출 수 있다. 이제 보유하는 재고가 완충재고이다.
6. **투기재고**(Speculative Inventory)  
   가격 상승이나 공급 부족을 예상하여 정상 수준보다 많이 확보하는 재고이다. 반도체 원재료 가격 상승이 예상되어 비용 절감 목적으로 현재 가격으로 대량 구매하는 경우가 해당된다. 예측이 잘못될 경우 과잉재고 및 자금 부담과 같은 문제가 발생한다.
7. **불용재고**(Dead Stock)  
   장기간 사용하지 않아 활용 가치가 떨어진 재고이다. 제품 단종, 설계 변경, 수요 감소, 품질 문제 등으로 발생할 수 있다.

### 재고 관리 주요 지표(KPI)

1. **재고회전율** (Inventory Turnover Ratio)

   재고가 얼마나 빠르게 판매 또는 생산에 사용되는지를 나타내는 지표이다.

   $$
   \text{재고회전율}
   =
   \frac{\text{매출원가}}{\text{평균재고}}
   $$

   연간 매출원가가 10억이고 평균 재고가 2억이면,

   $$
   \text{재고회전율}
   =
   \frac{10억}{2억}
   =
   5(회)
   $$

   이는 1년 동안 재고가 평균 5번 교체되었다는 의미이다. 일반적으로 재고회전율이 높을수록 재고 운영 효율이 좋다고 판단한다.

2. **재고일수** (Days Inventory Outstanding)

   현재 재고가 몇 일 동안 운영 가능한지를 나타낸다. 예를 들어 현재 재고가 30일분이면 공급이 중단되어도 약 30일 동안 생산 가능하다는 의미이다.

3. **결품률** (Stockout Rate)

   필요한 시점에 재고가 부족했던 비율이다. 낮을수록 좋다.

4. **재고 정확도** (Inventory Accuracy)

   시스템상 재고와 실제 재고가 얼마나 일치하는지 정도를 나타낸다. 예를 들어 ERP 상 재고가 부품 A 1,000개이고 실제 창고 부품 A가 980개이면 재고 정확도가 저하된다.

### 재고관리 주요 기법

1. **ABC 분석**  
   재고 품목을 중요도와 금액 기준으로 A, B, C 등급으로 분류하여 차별 관리하는 방법이다. 이 방법은 파레토 법칙(80:20법칙)을 기반으로 한다. 즉, 모든 품목을 동일하게 관리하지 않고 중요도에 따라 관리하는 방식이다.
   
    | 구분  | 특징                | 관리 방법  |
    | --- | ----------------- | ------ |
    | A등급 | 품목 수 적음, 금액 비중 높음 | 엄격한 관리 |
    | B등급 | 중간 수준             | 일반 관리  |
    | C등급 | 품목 수 많음, 금액 낮음    | 간단 관리  |
   
2. **EOQ**(Economic Order Quantity, 경제적 주문량)  
   재고 보유 비용과 주문 비용의 합을 최소화하는 최적 주문량을 결정하는 방법이다. 이는 주문 비용, 보관 비용, 연간 수요량 등을 고려하여 결정한다.
3. **안전재고**(Safefy Stock)  
   수요 증가나 공급 지연 등 불확실성에 대비하여 추가로 보유하는 재고이다. 자동차 운전자가 연료 부족을 대비하여 항상 일정량의 기름은 남겨두는 것과 같은 개념이다.
4. **MRP**(Material Requirements Planning)  
   자재소요계획, 생산계획을 기준으로 필요한 자재 종류, 수량, 구매 시점을 계산하는 시스템이다. 생산계획(MPS), 제품 구조(BOM), 재고 현황(IRF)을 입력 정보로 구매 계획, 발주 일정, 생산 일정을 산출한다.
   
    ```mermaid
    flowchart LR
    
    A["생산계획<br/>(MPS: Master Production Schedule)"]
    --> B["제품구조<br/>(BOM: Bill of Materials)"]
    --> C[현재재고 확인]
    --> D["필요 자재 계산<br/>(Net Requirements)"]
    --> E[구매 및 생산 계획]
    
    ```
    
5. **JIT**(Just In Time)
   필요한 부품을 필요한 시점에 필요한 양만큼 공급하여 재고를 최소화하는 생산 방식이다. 대표적으로 도요타 생산방식(TPS)에서 발전했다.
